# Saturday Studio – S2 (Salih Gulbay)

A small exploratory VR apartment made with **Meta Building Blocks** for **Unity 6000.6** (URP).

## Open
1. Clone this repository and add the folder in Unity Hub (Unity 6000.6.x).
2. Open `Assets/SaturdayStudio/Scenes/SaturdayStudio.unity` and press Play.

## In VR (Quest / Meta XR Simulator)
- **Move:** left thumbstick · **Turn:** right thumbstick
- **Grab:** grip button or hand pinch (Grab Interaction Building Block)
- **Make the bed:** point the ray at the bed and press the trigger / pinch

## Without a headset (desktop test mode, starts automatically)
WASD walk · mouse look · E or click: pick up / drop / use · Q or right-click: throw · scroll: hold distance

## Chores
- Carry the dirty dishes to the sink to wash them
- Make the bed
- Put the dirty clothes from the laundry basket into the washing machine
- Hang the wet clothes on the drying rack

The note on the wall tracks progress. All grabbable objects are custom procedural meshes (`Assets/SaturdayStudio/Meshes`), built by `Saturday Studio → Build Room`.
